# 収益化ロードマップ — 月30万円への現実的な道筋

> 数値は2026年7月時点の調査に基づく目安です（詳細な出典: `docs/research/affiliate-facts.md`）。
> 料率・上限は変動するため、各ASP管理画面で最新値を確認してください。

## 1. まず知っておくべき「時計アフィリの構造」

| 収益源 | 料率 | 上限 | 特徴 |
|---|---|---|---|
| 楽天アフィリエイト | 腕時計 2% | **1商品1,000円**・同一ユーザー月3,000円 | 高級時計でも1件最大1,000円。数で稼ぐ枠 |
| Yahoo!（バリューコマース） | 約1% | 案件による | LinkSwitch導入で自動リンク化 |
| Amazonアソシエイト | 時計 2% | **2024年8月に上限撤廃** | 100万円の時計成約で2万円。高額帯の本命 |
| **時計買取・査定リード** | 1件 4,500〜8,000円 | なし | ロレックス買取 約8,000円/件。**収益の柱** |
| Google AdSense | - | - | PV比例。月1万PVで数千円の底上げ |
| eBay Partner Network（将来） | 1〜5% | $100〜550/件 | 英語ページ×越境需要で拡張 |

**結論**: 「価格比較で集客 → 物販(楽天/Yahoo/Amazon)で小口収益 + 買取リードで大口収益」の二段構えが最短ルートです。
高級時計の検索者は「売る人」でもあるため、買取案件との相性が抜群です。

## 2. 月30万円の試算

- 物販のみの場合: 楽天上限1,000円 → 月300成約が必要 = 月1.5万〜3万クリック → **非現実的**
- **買取リード中心の場合**: 平均6,500円/件 × 46件 = 約30万円 → 必要クリックは月2,300〜4,600
- 必要トラフィック目安: **月間3万〜10万PV**（時計系は検索単価が高く、達成サイトは多数）

## 3. SEO戦略（このサイトの勝ち筋）

1. **ロングテール型番キーワード**: 「126610LN 最安値」「SBGA211 価格」など、型番×価格系は
   競合が弱く購買意欲が最高のキーワード。モデルページがそのまま受け皿になる。
2. **毎日更新**: 価格が毎日変わる=Googleが「生きているページ」と評価。sitemapも自動更新。
3. **構造化データ**: 全モデルページにProduct/AggregateOfferを出力済み。検索結果に価格が表示される。
4. **2言語**: 英語ページは「buy watches from japan」系の越境需要を取れる（将来eBay/JPY安と相乗効果）。

## 4. すぐやるべき収益アクション（優先順）

1. 楽天アフィリエイト + 楽天API（即日・無料）→ 公開初日から収益化
2. Google Search Console 登録（即日・無料）
3. バリューコマース登録 → Yahoo!提携 + LinkSwitch（審査1週間前後）
4. **A8.net / アクセストレード登録 → 時計買取案件と提携**（バイセル等。ここが月30万の鍵）
5. 独自ドメイン取得（SEOとAdSense審査対策）
6. AdSense申請（公開2〜4週間後、コンテンツが載ってから）
7. Amazonアソシエイト（審査: 180日以内に3成約）

## 5. 将来の拡張（実装済みの設計余地）

- **eBay / 海外店**: `scripts/fetch-prices.mjs` に fetchEbay を追加するだけで対応可能な構造
- **言語追加**: `lib/i18n.ts` の LANGS に追加（中国語・韓国語圏の需要も大きい）
- **買取枠**: モデルページに「このモデルを高く売るなら」セクションを追加（A8提携後）

## 6. 誠実な注意事項

- 収益はトラフィックに比例します。**公開直後の数ヶ月はほぼゼロ**が正常です。SEOは複利で効きます。
- 上記の数値は保証ではなく、2026年7月時点の料率に基づく試算です。
- 楽天APIの規約上、収益化は楽天アフィリエイト経由に限定され、取得データの恒久保存・再配布は禁止です
  （本システムは規約に適合する設計にしてあります）。
