# セットアップ手順（この順番で進めれば公開まで完了します）

所要時間の目安: 約2〜3時間（各サービスの審査待ちを除く）。
**すべて無料**です。クレジットカードも不要です。

---

## STEP 0. 前提（完了済み）

- Node.js と Git はこのPCにインストール済みです。
- サイト本体・自動化スクリプトは実装済みです。

## STEP 1. GitHub アカウントとリポジトリ

1. https://github.com/ でアカウントを作成（無料）
2. 右上「+」→「New repository」
   - Repository name: `watch-price-navi`
   - **Public** を選択（Publicだと GitHub Actions の実行時間が無制限・無料）
   - 「Create repository」
3. PowerShell でプロジェクトフォルダを開き、プッシュ:

```powershell
cd "C:\Users\uchida\Desktop\アフィリエイト用\watch-price-navi"
git remote add origin https://github.com/<あなたのユーザー名>/watch-price-navi.git
git push -u origin main
```

（初回は GitHub へのログイン画面が出るので指示に従ってください）

## STEP 2. GitHub Pages を有効化

1. リポジトリの Settings → Pages
2. 「Build and deployment」の Source を **GitHub Actions** に変更

これだけで、次回のワークフロー実行時に
`https://<ユーザー名>.github.io/watch-price-navi/` へ自動公開されます。

> **重要**: プロジェクトページ（上記URL形式）で公開する場合は、STEP 6 の
> `NEXT_PUBLIC_BASE_PATH` に `/watch-price-navi` を設定してください。
> 独自ドメイン（STEP 8）を使う場合は空のままにします。

## STEP 3. 楽天（アプリID + アフィリエイトID）

1. 楽天会員でログイン → https://webservice.rakuten.co.jp/
2. 「アプリID発行」→ アプリ名「watch-price-navi」等で発行 → **アプリID** と **アクセスキー** の両方を控える
   （楽天は2026年8月に新API基盤へ完全移行するため、アクセスキーが必要です）
3. https://affiliate.rakuten.co.jp/ にログイン → 「リンク作成」等の画面で **アフィリエイトID**（`xxxxxxxx.yyyyyyyy.xxxxxxxx.zzzzzzzz` 形式）を控える

## STEP 4. Yahoo!（Client ID）

1. Yahoo! JAPAN ID でログイン → https://e.developer.yahoo.co.jp/
2. 「アプリケーションの管理」→「新しいアプリケーションを開発」
   - 種類: サーバーサイド／利用API: ショッピング
3. 発行された **Client ID** を控える

## STEP 5. バリューコマース（Yahoo!ショッピングのアフィリエイト）

1. https://www.valuecommerce.ne.jp/ で無料会員登録（サイト審査あり。**サイトを一度公開してから**申請するのがおすすめ。先にSTEP 6〜7でサイトを公開できます）
2. 承認後、管理画面で「Yahoo!ショッピング」プログラムと提携申請
3. 広告スペースの **sid**（サイトID）と Yahoo!ショッピング広告の **pid** を控える
4. 「ツール」→「LinkSwitch」を有効化し、タグ内の `vc_pid = "…"` の値を控える

> バリューコマース承認前でも、楽天だけで収益化は始められます。
> VC_SID / VC_PID / NEXT_PUBLIC_VC_PID は後から追加すればOKです。

## STEP 6. GitHub に鍵と設定を登録

リポジトリの Settings → Secrets and variables → Actions で登録します。

**Secrets タブ（秘密の値）:**

| Name | 値 |
|---|---|
| `RAKUTEN_APP_ID` | STEP 3 のアプリID |
| `RAKUTEN_ACCESS_KEY` | STEP 3 のアクセスキー |
| `RAKUTEN_AFFILIATE_ID` | STEP 3 のアフィリエイトID |
| `YAHOO_APP_ID` | STEP 4 の Client ID |
| `VC_SID` | STEP 5 の sid（後からでも可） |
| `VC_PID` | STEP 5 の pid（後からでも可） |
| `ANTHROPIC_API_KEY` | **任意**。設定するとブログ記事がAI執筆になり品質が大きく上がります（月30本で百数十円）。未設定でもテンプレート記事が毎朝自動生成されます |

**Variables タブ（公開されてよい設定値）:**

| Name | 値 |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | `https://<ユーザー名>.github.io`（独自ドメインならそのURL） |
| `NEXT_PUBLIC_BASE_PATH` | `/watch-price-navi`（独自ドメインなら登録しない） |
| `NEXT_PUBLIC_VC_PID` | STEP 5 の LinkSwitch vc_pid（後からでも可） |
| `NEXT_PUBLIC_CONTACT_EMAIL` | お問い合わせ用メールアドレス |

## STEP 7. 初回実行

1. リポジトリの Actions タブ → 「Update prices & deploy」→「Run workflow」
2. 30〜50分ほどで完了し、サイトが公開されます（401モデル分の価格を取得するため時間がかかります）
3. 以後は全自動で動きます:
   - **毎朝 JST 6:00**: ブログ1本生成 → 価格更新 → 新作検出 → 公開
   - **毎夕 JST 18:00**: 価格更新 → 公開

## STEP 8. 独自ドメイン（強く推奨・年1,000〜2,000円程度）

SEOとAdSense審査のため、独自ドメイン（例: `tokei-navi.com`）の取得を強く推奨します。

1. お名前.com / Cloudflare Registrar 等でドメイン取得
2. リポジトリ Settings → Pages → Custom domain に入力し、案内どおりDNS設定（CNAME）
3. `NEXT_PUBLIC_SITE_URL` を新ドメインに変更し、`NEXT_PUBLIC_BASE_PATH` を削除
4. Actions からワークフローを再実行

## STEP 9. Google AdSense（サイト公開・記事掲載後に申請）

1. https://www.google.com/adsense/ で申請（独自ドメイン推奨）
2. 承認されたら `NEXT_PUBLIC_ADSENSE_CLIENT` に `ca-pub-…` を Variables 登録
3. AdSense 管理画面で「自動広告」をONにすれば広告掲載開始

## STEP 10. 検索エンジン登録

1. https://search.google.com/search-console でサイトを登録し、`sitemap.xml` を送信
2. https://www.bing.com/webmasters でも同様に登録
