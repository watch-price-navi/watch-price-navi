# 記事の下書き置き場

ここに置いた記事を、毎朝の実行が1本ずつ公開します。ファイル名の順（辞書順）に出ます。

Claude API に課金せずに、読み物として成立する記事を出し続けるための仕組みです。
下書きが尽きるとテンプレート版（型番と仕様の羅列）に落ちるので、
実行ログの「残り○本」を見て、少なくなったら書き足してください。

## 書き方

1ファイル1記事。JSON で次の項目を入れます。`date` と `slug` は公開時に付くので不要です。

```json
{
  "title_ja": "…",
  "title_en": "…",
  "description_ja": "…（160字以内）",
  "description_en": "…",
  "body_ja": "## 見出し\n\n本文…",
  "body_en": "## Heading\n\nBody…",
  "heroModel": "rolex/submariner-date-126610ln",
  "relatedModels": ["rolex/submariner-no-date-124060", "…"],
  "topics": ["ダイバーズ", "ロレックス"]
}
```

## 決まりごと

- `heroModel` と `relatedModels` は**カタログに実在するキー**にすること。無いものは公開時に捨てられます。
- 本文中のモデルへのリンクは `[名前](/ja/watch/ブランド/モデル/)` の形で書きます。
  この形が商品写真を差し込む目印にもなるので、崩さないこと。
  先頭に `/watch-price-navi` は**付けません**（公開時に自動で付きます）。
- 本文が200字未満の下書きは飛ばされます。
- 一度公開した下書きは `draftId`（ファイル名）で記録され、二度は出ません。
- 主役が重なると記事一覧に同じ写真が並ぶので、`heroModel` は下書きどうしでも重ねないこと。
